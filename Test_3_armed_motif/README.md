# Simulation scripts for 3-armed nanomotifs

To assess how 3-armed motifs behave in comparison to 4-armed motifs, this folder contains scripts to run and evaluate simulations of a 3-armed nanomotif. It includes scripts for oxDNA simulations and Bayesian optimisation of a bead-spring version of the nanomotif.
The simulations only serve as comparison point and are part of a separate project started by Xenia Schneider (https://github.com/Booklover4eva/KIT_Masterthesis_Xenia_Schneider).
